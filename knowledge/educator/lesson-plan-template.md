# Lesson plan template and worked example

Plan backwards: decide what students will be able to *do*, decide how you will see it, then choose activities. Fill the template top to bottom in that order.

## Template

```
Lesson: <title>            Class: <grade/group>     Length: <min>
Unit link: <what came before, what comes next>

1. Objective (student can…): <one observable verb + content>
2. Success criteria (student-facing, 2–4): "I can…"
3. Evidence: <the exit task or hinge question that shows it>
4. Prior knowledge needed: <and the 3 retrieval questions that check it>
5. Likely misconceptions: <1–3, with how you'll surface them>

Timeline
| Time  | Phase           | Teacher does | Students do | Check |
| 0–5   | Retrieval       |              |             |       |
| 5–15  | New content     |              |             |       |
| 15–30 | Guided practice |              |             |       |
| 30–45 | Independent     |              |             |       |
| 45–50 | Exit            |              |             |       |

Differentiation: support <…> / extension <…> / language access <…>
Materials: <list, with who prepares what>
If time runs short, cut: <which phase>
If it runs long, add: <ready extension>
```

## Writing good objectives

Use a verb you can see: *calculate, explain, compare, label, justify, write*. Avoid *understand, know, appreciate*: you cannot observe them, so you cannot check them. One objective per lesson is usually enough; two at most.

## Timing rules of thumb

- Transitions eat time. Allow extra for every change of activity, more with younger classes.
- Plan the cut line in advance. The exit task is the last thing to drop, because it tells you what to do tomorrow.
- Independent practice must be long enough to be real practice. If guided practice keeps overrunning, the example was too hard.

## Worked example (lower secondary maths, 50 min)

1. **Objective:** Students can find the area of a triangle from base and perpendicular height.
2. **Success criteria:** I can identify the perpendicular height. I can use area = ½ × base × height. I can give the answer in square units.
3. **Evidence:** Exit ticket: two triangles, one with a slanted side labelled as a distractor.
4. **Prior knowledge:** Rectangle area; halving. Retrieval: area of a 4 × 6 rectangle; half of 18; what does cm² mean?
5. **Misconception:** Using the slanted side as the height. Surface it with a hinge question showing three labelled lengths.

| Time | Phase | Detail |
|---|---|---|
| 0–5 | Retrieval | Three questions on mini-whiteboards |
| 5–15 | New content | Cut a rectangle diagonally; two worked examples, one obtuse |
| 15–20 | Hinge | "Which length is the height?" A/B/C; re-teach a different way if many miss it |
| 20–40 | Practice | Six blocked questions, then four mixed with rectangles and compound shapes |
| 40–50 | Exit | Two questions; sort into "ready" and "revisit" piles |

Support: printed triangles with the height already drawn. Extension: find a missing base given the area. Cut if short: the last four mixed questions.

## Common mistakes

- Activities chosen first, objective written afterwards to fit.
- Success criteria that restate the objective in teacher language.
- No plan for what happens with the exit-ticket results.
- A plan with no slack, which collapses at the first fire drill.
