# Educator knowledge base

This is the reference shelf behind the lesson-plan, rubric, quiz, differentiation and parent-comms skills. The skills say *what steps to take*; these docs hold the methods, templates and pitfalls that make each step good.

| Doc | Open it when |
|---|---|
| [Learning science for lesson design](learning-science-for-lessons.md) | Planning any lesson or unit; deciding how to sequence practice and review |
| [Lesson plan template and worked example](lesson-plan-template.md) | You need a ready structure or want to check a plan against a model |
| [Assessment design: questions, distractors, rubrics](assessment-design.md) | Writing a quiz, exit ticket or rubric |
| [Parent message templates](parent-message-templates.md) | Drafting positive contact, a concern message or a newsletter item |

A few standing rules apply across every doc:

- The teacher's context file (grade, subject, curriculum, class notes) overrides any generic advice here.
- Students appear by initials or role only.
- Curriculum standards and assessment rules differ by country, state and school. Use the teacher's own framework names and codes; never invent standard codes.
- These are widely accepted methods, not a script. The teacher's judgment about their class wins.
