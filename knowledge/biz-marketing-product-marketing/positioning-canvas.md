# Positioning canvas

Positioning is the context you set so the right buyers quickly understand what the product is, who it's for and why it's better for them than the alternatives. Messaging is how you then say it. Do positioning first; messaging written without it drifts into feature lists and adjectives.

## Work through the canvas in this order

The order matters: each step depends on the one before.

### 1. Competitive alternatives

What would the customer do if we didn't exist? Include the boring answers: a spreadsheet, an agency, hiring someone, doing nothing, a big suite they already own. Source these from win/loss notes and sales calls, not from a list of companies we think of as competitors.

### 2. Unique attributes

What do we have that those alternatives don't? Capabilities, approach, expertise, data, business model. Only list what's true and shipped. For each, note the proof (demo, metric, customer quote).

### 3. Value (and proof)

For each unique attribute, what does it let the customer achieve? Group attributes into two or three value themes. Write value in customer outcomes ("close the books in half the time"), not features ("automated reconciliation"). Every value needs proof you can show.

### 4. Best-fit customers

Who cares most about that value? Describe the characteristics that make someone a great fit: size, situation, trigger events, tools, team shape. Use closed-won data: who buys fastest, churns least, expands most. A narrow best-fit is a strength; you can still sell to others.

### 5. Market category

The frame of reference that makes the value obvious. Pick the category where buyers already understand the rules and where our differentiators look like strengths. A new category is expensive to create; prefer an existing one, or an existing one with a qualifier ("X for finance teams").

### 6. Relevant trends (optional)

A real, verifiable change in the world that makes this matter now. Only use it if it's true and the customer feels it.

## Canvas template

```markdown
# Positioning: <product or segment> — <date>

| Element | Content | Evidence |
|---|---|---|
| Competitive alternatives | | win/loss ref, call notes |
| Unique attributes | | shipped? demo link |
| Value themes (2–3) | | quote, metric |
| Best-fit customer | | CRM segment data |
| Market category | | how buyers describe us |
| Trend (optional) | | source |

## Positioning statement (internal, not copy)
For <best-fit customer> who <need/trigger>, <product> is a <category>
that <key value>. Unlike <main alternative>, we <key differentiator>.
```

## From positioning to messaging hierarchy

```markdown
## Headline message
<one sentence, outcome-led, for the best-fit customer>

## Value pillars (one per value theme)
### Pillar 1: <outcome>
- Supporting points: <2–3 features that deliver it>
- Proof: <quote / metric / case study>
### Pillar 2 …

## By audience (if roles differ)
- Economic buyer: <what they care about>
- Day-to-day user: <what they care about>

## Words we use / avoid
```

## Testing positioning

Positioning is a hypothesis until it changes outcomes.

- **Sales calls:** reps use the new opener for a few weeks; capture where prospects lean in or get confused.
- **Message testing:** show two or three versions of the headline and pillars to best-fit customers in interviews; ask them to explain the product back in their own words. If they can't, it isn't clear.
- **Landing page or ad tests:** useful signals, with the testing caveats in the demand gen playbook.
- **Win rate:** watch win rate by segment and competitor after a change (see [metrics](win-loss-and-metrics.md)).

## When to refresh

- A new segment or major launch changes who it's for or what's unique.
- Win rate against a specific alternative drops.
- Sales consistently re-pitches it in their own words because ours don't work.
- A competitor ships what used to be our differentiator.

## Common mistakes

- Starting with the category or the tagline.
- Listing every feature as a differentiator.
- Value claims with no proof.
- Writing for everyone; nobody feels it's for them.
- Positioning against a competitor the customer has never considered.
- Letting messaging run ahead of the product: if it's not shipped, it's not in the positioning.
