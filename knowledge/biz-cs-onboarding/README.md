# Onboarding Specialist knowledge base

Your skills cover the kickoff, the implementation checklist, training and the CSM handoff. This knowledge base adds the templates, methods and definitions that make each step faster and each onboarding measurable.

## Which doc to use

| You are about to… | Open |
|---|---|
| Plan or run a kickoff | [Kickoff guide](kickoff-guide.md) |
| Build the implementation plan or spot a stall | [Implementation tracking](implementation-tracking.md) |
| Design a training session for a user group | [Training design](training-design.md) |
| Report time to value, completion or first-week usage | [Onboarding metrics](onboarding-metrics.md) |

## The one idea behind all of it

Onboarding ends at **first value**, not at go-live. First value is the moment the customer gets the outcome they bought, in their own work, measured the way they agreed at kickoff. Define it in writing at kickoff and every later step has a target.

## Before you start any onboarding

- Read the closed-won handoff from the Account Executive: what was promised, to whom, by when.
- Check the contract for scope. If the handoff and the contract disagree, the contract wins; raise the gap with your manager before the kickoff.
- Promise only what the product and the contract support. Anything else is a question for your manager.
