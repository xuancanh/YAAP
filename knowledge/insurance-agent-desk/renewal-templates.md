# Renewal templates

Drafts for the agent to adapt and send. They ask for a conversation or confirm facts; they never recommend coverage.

## Outreach by tier

**Tier 1: flagged change or premium jump (about 60 days out)**
> Hi [name], your [home] policy renews on [date]. You mentioned [the renovation] earlier this year, so it'd be worth 15 minutes to make sure the policy still fits. Do any of these times work? [times]

**Tier 2: clean renewal (about 45 days out)**
> Hi [name], your [auto] policy with [carrier] renews on [date]. Has anything changed: drivers, vehicles, how you use the car, or your address? If not, there's nothing you need to do. Just reply and let me know either way.

The "anything changed?" question is the net that catches unflagged life changes. Keep it in every clean-renewal touch.

**Tier 3: renewal with remarket (agent has chosen to shop it)**
> Hi [name], your renewal came in at [premium as recorded]. [Agent] is checking options with other carriers and will be in touch by [date] with what we find.

## Unresponsive-client ladder

Each step is logged with date, channel and content.

| Days before renewal | Step |
|---|---|
| 60 | Tier email or letter |
| 45 | Follow-up by a second channel (phone or text, per the client's preference) |
| 30 | Letter or email stating the renewal date and what happens if there's no response, per the carrier's process |
| 14 | Final notice from the agent, logged |
| After renewal or lapse | Follow-up per carrier's reinstatement process (agent-verified) |

The ladder exists for two reasons: most clients just need a reminder, and the agency needs a record that it tried.

## Quote comparison sheet (facts only)

Assemble from the quotes as received. The agent does the comparing and advising.

```
Client: [code]           Line: [home]         Renewal date: [date]
Prepared: [date]         For: [agent]

| Item                    | Current ([carrier]) | Quote A ([carrier]) | Quote B ([carrier]) |
|-------------------------|---------------------|---------------------|---------------------|
| Premium (annual)        |                     |                     |                     |
| Deductible(s)           |                     |                     |                     |
| Key limits (as quoted)  |                     |                     |                     |
| Endorsements included   |                     |                     |                     |
| Notable exclusions (as stated in quote) |      |                     |                     |
| Payment options         |                     |                     |                     |
| Quote valid until       |                     |                     |                     |
| Documents received      |                     |                     |                     |

Differences noted (facts, not opinions):
- Quote A lists water backup as excluded; current policy includes it as an endorsement.
- Quote B quote expires [date].

Open questions for the agent:
- [ ]
```

Write each difference exactly as the documents state it. "Quote A is worse" is an opinion; "Quote A has a higher wind deductible" is a fact.

## Renewal tracker states

untouched → outreach sent → review scheduled → quoted → decided → bound/renewed → closed (with outcome and reason).

Record the reason for every lost renewal (price, service, moved, coverage need ended). The quarterly view depends on it.

## Common mistakes

- Sending the clean-renewal message to a flagged client and missing the review.
- Writing "you're fully covered" in a draft. Remove it; it's a coverage statement.
- Letting the ladder slip because the client "usually renews anyway".
- Comparison sheets that mix premiums from different coverage levels without saying so.
