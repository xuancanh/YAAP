# Claim file checklist

A claim is the moment clients find out what their insurance is worth. The desk's job is to organise it so nothing is missed and the client always knows what's next.

## First notice of loss (the day they call)

Capture as reported:

- [ ] Client and policy (number from the file, carrier).
- [ ] What happened, when, where.
- [ ] Anyone injured? (If yes and it's ongoing, emergency services first.)
- [ ] Other parties involved: names, contact, their insurer if known; police or incident report number.
- [ ] What's been done to prevent further damage.
- [ ] Photos or video taken?
- [ ] Best way and time to reach the client during the claim.

Then:

- [ ] Look up the carrier's reporting process and deadlines (agent-verified).
- [ ] Report to the carrier, or help the client do so, per the agency's process.
- [ ] Record the claim number and adjuster when assigned.

## Client's immediate-steps sheet

Draft from the carrier's own guidance where available. The NAIC's general consumer guidance for property claims includes:

- **Report promptly;** policies have reporting deadlines.
- **Document before cleaning up:** photos and video of all damage, and a list of damaged items.
- **Make temporary repairs** to prevent more damage (a tarp, boarding a window), and keep receipts.
- **Hold off on permanent repairs** until the insurer has inspected or agreed.
- **Keep damaged items** if possible, for inspection.
- **Keep a log** of every call: date, name, what was said.
- **Be wary of contractors** who show up uninvited after a disaster or want full payment upfront.

## Stage tracking

| Stage | Date | Carrier's stated timeline | Actual | Next action |
|---|---|---|---|---|
| Reported | | | | |
| Acknowledged | | | | |
| Adjuster assigned | | | | |
| Inspection | | | | |
| Decision | | | | |
| Payment/settlement | | | | |
| Closed | | | | |

When a stage runs past its stated timeline, draft a polite status inquiry the same day. Update the client after every stage change, even if the news is "still waiting":

> Quick update on your claim: the adjuster has inspected and is preparing the estimate. They expect to have it by [date]. Nothing you need to do right now. I'll let you know as soon as I hear.

## When it goes wrong

**Delayed:** status inquiry → follow-up to the adjuster's supervisor → agent escalation within the carrier.

**Disputed or denied:** gather the denial in writing with its stated reasons, the policy wording cited, and the timeline, for the agent. Options the agent may discuss with the client, per the NAIC's consumer guidance, include the insurer's internal review, an appraisal clause if the policy has one, and the state insurance department's complaint process. Some clients choose a public adjuster or an attorney.

The desk organises facts; interpreting the policy and advising on a dispute is the agent's work, and legal questions go to a lawyer.

## Closing the file

- [ ] Outcome and amount recorded.
- [ ] Client's experience noted; flag retention risk after a rough claim.
- [ ] Claims history updated for the next renewal.

## Common mistakes

- Telling the client "that'll be covered" before the carrier decides.
- No update for weeks because there was "nothing new".
- Permanent repairs before inspection, without the carrier's agreement.
