# Constraint prompt bank

Constraints help because they narrow the choices. "Write anything" stalls people; "write a scene told only in questions" gives them a place to start.

## 1. Diagnose the block (one question)

"What does stuck feel like right now?"

| Answer sounds like | Block | What helps |
|---|---|---|
| "I've got nothing" | No ideas | Prompts and constraints (below) |
| "I've got too many ideas" | Can't choose | A forcing choice: pick one in 60 seconds, or roll a die |
| "I'm scared to touch the main piece" | Fear of this piece | A low-stakes side project in the same world or style |
| "I haven't done it in ages" | Rust | Warm-ups with no quality bar |
| "I'm exhausted" | Depletion | Rest or input (read, listen, walk), not more output |

## 2. Serve three options, one line each

Then step back. If one sparks interest, offer the five-minute version to lower the bar.

## Prompts by medium

**Writing**

- A scene told entirely in questions.
- Two characters want the same object for different reasons.
- Describe a room so the reader knows who lives there without meeting them.
- Rewrite a fairy tale from the villain's side, in 300 words.
- A letter that's never sent.
- Every sentence starts with the next letter of the alphabet.

**Music**

- Eight bars using only three notes.
- A melody built from your phone number.
- Write a song in a style you don't usually play.
- One chord, four minutes; vary only rhythm and dynamics.
- Set a short poem or text message to music.

**Drawing and painting**

- Draw your non-dominant hand with your dominant one, three times in five minutes each.
- Only three colours today.
- Draw an object without lifting the pen.
- The same mug from five viewpoints.
- Thirty one-minute gesture drawings.

**Photography**

- Shoot only reflections.
- One lens, one focal length, one street.
- Twenty photos of a single object.
- Only shadows; no people visible.
- A sequence of five photos that tells a story.

**Any medium**

- Make something deliberately bad, as fast as possible.
- Finish something in 20 minutes.
- Copy a work you admire as closely as you can, then change one element.

## Warm-ups (two minutes, disposable)

- **Writing:** free-write without stopping; morning pages if that's their practice.
- **Music:** scales, long tones, or improvise over a drone.
- **Drawing:** loose circles and lines, gesture sketches.
- **Photography:** five quick shots of whatever's near.

Say it out loud: this isn't meant to be good.

## Tracking what works

Log each prompt offered: date, prompt, taken or not, and whether it became something. Over time you'll learn which kinds of prompts this person responds to. On a blocked day, the best evidence is a past spark that turned into finished work.

## Worked example

User: "I want to draw but nothing comes."

Diagnose: "I've got nothing" → prompts.

Offer: "1) The same mug from five angles. 2) Only three colours, any subject. 3) Thirty one-minute gestures from a video of people walking." User picks 3. Five-minute version: "Just do five gestures and see how it feels."
