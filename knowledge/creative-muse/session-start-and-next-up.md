# Session start and the next-up note

The hardest part of a session is the first five minutes. The fix is to end each session by setting up the next one.

## Ending a session: the next-up note

Before stopping, write two or three lines:

```
Next up: [the very next concrete thing, e.g. "Mara opens the letter; she already knows what it says"]
Why it matters: [what this moment does for the piece]
First line or move (optional): [a sentence, a chord, a sketch idea to start from]
```

Good next-up notes are specific enough to start without thinking. "Work on chapter 7" isn't one; "Write the argument in the car — she says the thing she's been avoiding" is.

Some writers stop mid-sentence or mid-scene on purpose, so the next session starts with something easy to finish.

## Starting a session

1. Read the next-up note.
2. Re-read the last page or listen to the last take (not the whole project).
3. Two-minute warm-up if rusty (see [constraint prompt bank](constraint-prompt-bank.md)).
4. Start with the next-up move. Don't edit yesterday's work first; it eats the session.

If the note doesn't spark anything, try the five-minute version: "Just write the first exchange of dialogue." Starting small often turns into a full session.

## Progress log

Keep it light enough to fill in every time:

```
Date | Time spent | Output (words / scenes / bars / sketches) | One-line note | Next up written? ✓
```

Look at it weekly, not daily. Patterns worth noticing:

- Sessions that go well: time of day, place, what came before.
- Gaps: what interrupted?
- Slowdowns in one part of the project.

## The middle slump

Most long projects sag somewhere in the middle. Diagnose before pushing harder:

| Symptom | Likely cause | Try |
|---|---|---|
| Don't know what happens next | Outline gap | Brainstorm five possible next events, pick the most surprising that still fits |
| Know what happens, dread writing it | The scene may be skippable | Ask what the reader loses without it; if nothing, cut or summarize |
| Everything feels flat | Wrong point of view or distance | Rewrite one page from another character or closer in |
| Bored with the project | Lost the reason for it | Re-read the premise file: what promise does this piece make? |

## Deadline maths

For a word-count goal: remaining words ÷ remaining sessions = words per session. If that number is more than the person's usual output, adjust now: more sessions, smaller goal, or a later date. Saying so early is kinder than a crunch.

## Worked example

User ends a session frustrated: "The scene didn't work."

Help them write a next-up note anyway: "Next up: try the scene from her brother's side. He's the one with something to lose." Next session starts with a fresh angle instead of the same wall.

## Common mistakes

- Stopping at a natural end point, so the next session starts cold.
- Rewriting the opening again instead of moving forward.
- Logging only good days; the bad days hold the useful patterns.
