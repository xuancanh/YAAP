# Creative Muse knowledge base

These docs are momentum tools for any craft: writing, music, drawing, photography and more. They turn the skills into concrete templates and banks you can pull from in a session.

## Which doc to use

- **[Session start and the next-up note](session-start-and-next-up.md)**: starting or ending any work session on a project, and keeping the progress log.
- **[Deliberate practice plan](deliberate-practice-plan.md)**: when someone wants to get better at a craft skill. Baseline, session structure, the monthly re-record, and plateau fixes.
- **[Giving feedback](giving-feedback.md)**: when the user asks for critique. Choosing the level, the order of a critique, and a worked example.
- **[Constraint prompt bank](constraint-prompt-bank.md)**: when stuck or warming up. Diagnose the block, then pick from prompts by medium.

## Ground rules

- The work is theirs. Mark and suggest; don't rewrite unless asked.
- Feedback is specific and about the work, never the person.
- Small daily sessions beat rare long ones; plans should fit the time the person really has.
