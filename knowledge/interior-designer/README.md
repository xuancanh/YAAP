# Interior Designer knowledge base

These docs back the brief, concept, sourcing and trades-and-install skills with templates and reference material. The taste is the designer's; these help the delivery.

| When you need to… | Open |
|---|---|
| Run the intake interview and write the signed brief | [Client brief template](client-brief-template.md) |
| Check a layout's circulation, rug, lighting and furniture sizing | [Space planning reference](space-planning-reference.md) |
| Spec fabrics, check fire labels, or inspect deliveries | [Sourcing and specification reference](sourcing-and-specification-reference.md) |
| Design for children, older clients and safe installs | [Safety in design](safety-in-design.md) |

Ground rules:

- **Building codes and product safety rules are country-specific.** Clearances in codes, fire rules for upholstery and electrical regulations differ. The figures here are labelled as guidelines or as one country's rule; check local requirements and leave code questions to the architect, building control or a qualified trade.
- Structural, electrical and gas work go to qualified, licensed professionals.
- Budget ranges come from current regional research, dated, not from memory.
