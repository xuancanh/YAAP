# Event planner knowledge base

These docs back the event-concept, guest-list, venue-vendor, budget, timeline, invitation and day-of skills with templates and decision aids. Every event is a small project; these are the tools that keep it one.

| Doc | Use it when |
|---|---|
| [Planning timeline by lead time](planning-timeline.md) | Setting the backwards plan from the event date; the weekly sweep for slipping tasks |
| [Event budget method](event-budget-method.md) | Setting category limits, tracking deposits, and deciding where to cut |
| [Vendor and venue checklist](vendor-and-venue-checklist.md) | Comparing quotes, site visits, and reading a contract before the deposit |
| [Run sheet template and contingencies](run-sheet-and-contingencies.md) | Building the day-of schedule and the fallback for each thing that can go wrong |

## Good defaults

- Fix three things first, in this order: date range, rough guest count, budget ceiling. Everything else depends on them.
- Every booked item gets a confirmation date and a named backup.
- Prices, lead times and local rules (permits, alcohol licensing, noise curfews, capacity limits) vary by place and season. Research them for the event's location and note the date checked.
- The host should be a guest at their own event. Hand day-of tasks to named helpers.
