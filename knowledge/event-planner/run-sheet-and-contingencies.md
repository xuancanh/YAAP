# Run sheet template and contingencies

A run sheet lets the host hand the day to helpers. Every line has a time, a task, an owner and a backup. If a line has no owner, it will not happen.

## Run sheet template

```
Event: <name>     Date: <date>     Venue: <address>     Venue contact: <name, phone>
Day lead (not the host): <name, phone>

Contacts
| Role | Name | Phone | Arrives |

Timeline
| Time | What happens | Owner | Notes / backup |
| 10:00 | Rentals delivered | Sam | Delivery window 10–12; call Rentals Co if late |
| 14:00 | Decor setup | Sam + Ana | Photos of layout in folder |
| 17:30 | Caterer arrives | Venue lets in | Kitchen access via side door |
| 18:30 | Doors open, drinks | Bar staff | |
| 19:15 | Welcome speech (3 min) | Host | Mic tested at 18:00 |
| 19:30 | Dinner served | Caterer | Dietary plates flagged by name card |
| 21:00 | Cake | Ana | Knife, lighter, plates in kit |
| 23:00 | Music off (venue curfew) | DJ | |
| 23:30 | Pack-down | Sam + 2 | Rentals collected next day 10:00 |
```

Pad the schedule. Things run late; key moments (speeches, cake) should have slack before hard stops like curfew.

## Day-of kit

- printed run sheet and contact list;
- phone chargers and a power strip;
- tape, scissors, string, cable ties, pens, marker;
- lighter, cake knife and server;
- basic first-aid kit; any medical supplies the host or guests asked for;
- stain remover, tissues, safety pins, sewing kit;
- cash for tips and emergencies;
- rubbish bags;
- spare copies of the seating plan or name cards;
- umbrellas if any part is outdoors.

## Contingency table

| What goes wrong | Fallback |
|---|---|
| Rain on an outdoor event | Agreed indoor space or tent booked with a decision time (e.g. the day before) |
| Vendor no-show | Named backup vendor's number; day lead calls the vendor at the planned arrival time, not later |
| Running late | Know which item to cut (second speech, a game) and protect the hard stop |
| Too many guests | Food buffer agreed with caterer; spare chairs location |
| Too few guests | Rearrange to fill tables; tell the caterer what can be packed for guests to take home if allowed |
| Tech fails (mic, music) | Phone + portable speaker; speeches done without mic in a smaller circle |
| Guest unwell or injured | First-aid kit; venue's first-aider; emergency number. The day lead calls; the host stays with guests |
| Dietary mix-up | Caterer confirms labelled plates; one spare safe meal |

## Final-week confirmations script

"Hi, confirming for Saturday the 14th at Riverside Hall: arrival 17:30, service from 19:30, 42 guests including 3 vegetarian and 1 gluten-free. The day contact is Sam on 07… Anything you need from us?"

## Common mistakes

- The host is also the day lead, and spends the party fixing things.
- Times without owners.
- Nobody knows the venue contact's number.
- No decision time for the rain plan, so it is decided too late.
