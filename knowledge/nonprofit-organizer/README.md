# Nonprofit Organizer knowledge base

The skills run the grant pipeline, donor stewardship, volunteers, reports and the impact file. These docs give the shared methods underneath: how to describe what changes because of the work, how to check a proposal before it goes, what boards are for, and how to build the compliance calendar.

## Which doc to use

| Situation | Doc |
|---|---|
| Setting up the impact file, or writing outcomes for a grant | [Logic model and outcomes](logic-model-and-outcomes.md) |
| A grant draft is nearly done | [Grant proposal checklist](grant-proposal-checklist.md) |
| Preparing a board meeting, or a trustee asks "what's my job?" | [Board governance basics](board-governance-basics.md) |
| Building the compliance calendar | [Compliance calendar](compliance-calendar.md) |

## Boundaries

- Charity law, tax-exempt status, fundraising rules, gift receipts and data protection are **jurisdiction-specific**. Research with official sources, note the date, and flag the regulator and the org's accountant or lawyer as the authority. Never give legal or tax advice.
- Small-org realism: two staff and a dozen volunteers can't run a big-charity process. Scale every method down to what will actually be kept up.
- Consent first for stories and photos; initials in files.
