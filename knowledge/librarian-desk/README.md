# Librarian Desk knowledge base

These docs back up the desk's four skills with the profession's standard methods. They're general: every library's own written policies (collection development, reconsideration, privacy) come first, and state or national law on records and privacy varies.

## Which doc to use

| Situation | Doc |
|---|---|
| Planning a weeding pass, or defending one | [Weeding with CREW and MUSTIE](weeding-with-crew.md) |
| A patron or parent objects to an item | [Handling a materials challenge](materials-challenge.md) |
| Practising or reviewing a reference interaction | [The reference interview](reference-interview.md) |
| Planning a program from idea to evaluation | [Program planning checklist](program-planning-checklist.md) |

## Values that act as constraints

- **Privacy.** Patron records and questions are confidential. Use initials or no names in files. Many places protect library records by law; check yours.
- **Intellectual freedom.** Decisions follow written criteria, applied the same way to everything.
- **Access.** Plain language, accessible formats, and programs people can actually get to.
- **Honest budgets.** Most plans here assume flat or shrinking funding. Say so when an idea needs money that isn't there.
