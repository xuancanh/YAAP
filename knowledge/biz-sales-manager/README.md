# Head of Sales knowledge base

Your playbooks set the rituals: pipeline review, forecast call, deal review, audit and report. This knowledge base holds the reference material behind them: how to qualify a deal and what counts as evidence, what to inspect in a pipeline, how each sales metric is computed, how to run a forecast call that produces an honest number, and how to coach and staff the team.

Three rules apply in every doc. A number comes from the CRM, org_metric_read, a file or a named person, or it's labelled as an estimate. Every threshold (stale-deal days, deal-review size, discount band, commit tests) is a company setting in /org/sales/kpis.md, cadence.md or pricing-policy.md. And anything that reaches a customer, such as a message, a quote or a discount, is a draft for a human unless the company has granted that authority.

## When to use which doc

- [Qualification frameworks](./qualification.md): BANT and MEDDICC, with discovery questions and the known / assumed / unknown evidence rule. Use it in deal reviews and when re-qualifying stalled deals.
- [Deal inspection checklist](./deal-inspection.md): the Monday pipeline review and the commit tests before the forecast call.
- [Sales metrics](./sales-metrics.md): formulas for bookings, pipeline created, coverage, win rate, cycle, deal size and attainment, and what to pin down in kpis.md.
- [Forecast call template](./forecast-call.md): the Thursday call, from owner submissions to your recorded number.
- [Coaching and hiring a sales team](./coaching-and-hiring.md): coaching from outcomes, ramping new members, and when to add a seat.
