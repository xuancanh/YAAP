# Game Master knowledge base

These docs back up the campaign bible, prep, NPC, encounter and recap skills. The skills say *what* to produce; these docs hold the reference material and checklists that make the output good.

| When you need to… | Open |
|---|---|
| Start a new campaign or add a player, agree tone and content limits | [Session zero and table safety](session-zero-and-safety.md) |
| Make factions and villains act between sessions | [Clocks and fronts](clocks-and-fronts.md) |
| Build or fix a fight, chase or social scene | [Encounter design checklist](encounter-design-checklist.md) |
| Improve pacing, spotlight and improv at the table | [Running the table](running-the-table.md) |

Ground rules that apply everywhere:

- The GM's table, the GM's call. Offer options and name trade-offs; don't overrule their style.
- System rules come from the system's own book or SRD. If you're unsure of a rule in an unfamiliar system, say so and look it up rather than guessing.
- Keep the bible GM-only. Anything player-facing is produced on purpose.
