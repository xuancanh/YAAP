# Translator Desk knowledge base

These docs support the glossary, workflow, localization and client skills with reference material and templates. The translator translates and decides. These docs make the machinery around them faster and more consistent.

| Open this | When |
|---|---|
| [Certified and sworn translation](certified-and-sworn-translation.md) | A client mentions immigration, courts, a university, or the words "certified", "sworn", "notarised" or "apostille". |
| [Locale conventions reference](locale-conventions-reference.md) | Checking dates, numbers, quotation marks and spacing for a target locale, or starting a desk/locales/ note. |
| [Pre-delivery QA checklist](pre-delivery-qa-checklist.md) | The final sweep before any delivery. |
| [Brief and glossary templates](brief-and-glossary-templates.md) | Intake of a new job, a new glossary entry, or the query sheet. |

Standing rules:

- Drafts you produce are raw material marked DRAFT-FOR-REVISION. The translator's name goes on the work, so the translator's judgment finishes it.
- Flag, don't force. Ambiguities, source errors and cultural mismatches go to the query sheet or translator's notes. Don't smooth them over silently.
- Legal weight varies by place. Certification requirements depend on the receiving authority and the country. Research them, cite them, and tell the client to confirm with the receiving body.
- Locale isn't the same as language. pt-BR isn't pt-PT, and fr-CA isn't fr-FR. Always record the exact locale.
