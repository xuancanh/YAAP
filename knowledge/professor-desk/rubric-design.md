# Rubric design and consistent grading

A rubric makes grading faster, fairer and easier to defend. The professor sets and approves the rubric and decides every final score; drafts propose, never decide.

## Analytic or holistic?

| Type | What it is | Use when |
|---|---|---|
| Analytic | Separate criteria, each scored on levels | Feedback matters; several skills assessed; multiple graders |
| Holistic | One overall level with a description | Quick judgments; low-stakes work; experienced grader |
| Single-point | Criteria with only the "meets expectations" description; space for above/below notes | Formative work; you want comments, not boxes |

## Building an analytic rubric

1. **Criteria from outcomes.** Three to six criteria, each tied to a course outcome. "Argument", "Use of evidence", "Method", "Clarity". Not "Effort".
2. **Levels.** Three to five. Four avoids a lazy middle.
3. **Describe each level in observable terms.** "Claims are supported with at least two relevant sources, each explained" beats "Good use of evidence".
4. **Weight the criteria** to match what matters most.
5. **Test it** on three real submissions before releasing it. If two graders disagree, the description is vague.

**Example criterion: Use of evidence (weight 30%)**

| Level | Description |
|---|---|
| 4 | Every main claim supported by relevant, credible evidence that is explained and linked back to the argument |
| 3 | Most claims supported; some evidence listed rather than explained |
| 2 | Evidence present but often irrelevant, unexplained or from weak sources |
| 1 | Claims largely unsupported |

## Calibration before the batch

- Grade three to five submissions spanning the range, then pin them as anchor examples for each level.
- With teaching assistants: everyone grades the same few, compares, and agrees on the reasons before splitting the pile.
- Write down any decisions made ("missing citations in one paragraph = level 3, not 2") so they apply to the whole batch.

## Staying consistent during the batch

- Grade one criterion across all submissions, rather than one submission across all criteria, when consistency matters most.
- Shuffle the order; fatigue and early anchoring drift scores.
- Grade anonymously where the platform allows.
- Re-check the first ten at the end; early scores often differ from later ones.
- Keep a list of common errors so the same mistake gets the same deduction.

## Feedback students can use

Per criterion, aim for one strength, one specific improvement, and how to make it next time:

> Evidence: Your use of the 2019 survey in section 2 really carries the argument. In section 3, the claims about cost aren't supported yet; next time, find one source for each number and say why it matters.

Reusable comment banks save time; personalise the first line so it doesn't read as a stamp.

## Regrades

Follow the syllabus process. Re-read against the rubric and anchors, not against the student's argument about effort. Record the outcome and reason.

## Common mistakes

- Criteria that overlap ("Analysis" and "Critical thinking"), so one flaw is penalised twice.
- Level descriptions that just say excellent/good/fair/poor.
- Releasing the rubric after the assignment is due.
- Feedback that justifies the grade but doesn't help the next piece of work.
