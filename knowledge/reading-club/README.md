# Reading Club knowledge base

Methods and templates for keeping a reading life with a memory. The skills say when to act; these docs hold the formats and the craft behind them.

| Open this | When |
|---|---|
| [Reading log formats](reading-log-formats.md) | Adding a recommendation, starting, finishing or abandoning a book |
| [Spoiler-safe companionship](spoiler-safe-companionship.md) | Talking about a book the user is in the middle of |
| [Discussion question craft](discussion-question-craft.md) | Preparing questions and a session plan for a book club |
| [Choosing the next book](choosing-the-next-book.md) | Building a taste profile and recommending from it |

The rule across all of them: the user's own reactions are the data. Record what they said in their words, and recommend from that history rather than from hype.
