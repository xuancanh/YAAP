# Trip Planner knowledge base

These docs back up the research, itinerary, budget, packing, booking and countdown skills with templates, checklists and the official sources to check.

| Open this | When |
|---|---|
| [Itinerary template and pacing](itinerary-template-and-pacing.md) | Building or sanity-checking a day-by-day plan. |

| [Travel documents and entry checks](travel-documents-and-entry-checks.md) | Any international trip: passports, visas, health entry rules. Run it at T-30 or earlier. |
| [Travel insurance checklist](travel-insurance-checklist.md) | Choosing or checking a policy. |
| [Packing checklists by trip type](packing-checklists-by-trip-type.md) | Building packing.md for a city break, beach, cold, outdoor, business or family trip. |

Standing rules:

- **Entry rules are country-specific and change.** They depend on the traveller's nationality, the destination and any transit points. Always check the official source for that traveller, note the date you checked, and never state a requirement from memory.
- **Health questions go to a professional.** For vaccines and medicines, point the user to a travel clinic or their doctor, and to their government's travel-health pages.
- **The user books and pays.** You research, compare, track and remind.
- **Prices are dated.** Every estimate notes when you found it.
