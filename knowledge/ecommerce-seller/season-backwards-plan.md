# Season backwards plan

Plan each peak from the hard wall backwards: the last date an order can ship and still arrive in time. Everything else is scheduled before it.

## 1. Find your peaks

From last year's sales, mark the weeks well above average. Common ones: the end-of-year holidays for most sellers, plus category peaks such as Valentine's Day, Mother's or Father's Day, wedding season, back-to-school or summer.

## 2. The backwards timeline

Fill in this table for each peak:

| Milestone | Date | Notes |
|---|---|---|
| Peak date (the event) | | |
| Last order date for on-time delivery | | Check each carrier's and marketplace's published cutoffs for that year; add a margin |
| Stock in hand and ready to ship | | Before orders surge |
| Production run or supplier order delivered | | Lead time from [reorder point math](reorder-point-math.md) |
| Production starts / supplier order placed | | |
| Listings refreshed, gift photos and copy | | |
| Ads and email campaign live | | |
| Supplies ordered (boxes, tape, inserts) | | These run short in peak too |

Carrier cutoffs are published each year and differ by service and destination. Use the current year's dates.

## 3. Maker capacity check

```
Units you can make per week: ___
Weeks available before the stock-in-hand date: ___
Capacity = units/week × weeks = ___
Forecast for the peak (last year × growth estimate): ___
Gap: ___
```

If forecast exceeds capacity, decide early:

- Start production sooner and batch the bestsellers.
- Simplify: fewer variants or a simpler version of the bestseller.
- Cap orders: set a maximum or close custom orders on a date.
- Raise the price on high-effort items.
- Get help: temporary help with packing or finishing.

These options exist only if you decide while there's still time.

## 4. Peak ops pack

- **Processing times** updated on the shop and listings so buyers know when items ship.
- **Shipping cutoff notice** on the shop banner and in listing descriptions.
- **Message templates:**
  - "Where's my order?": tracking link, expected date, what to do if it's late.
  - "Will it arrive by…?": honest answer based on cutoffs.
  - Delay notice (if you can't ship on time, the rules on telling buyers and offering cancellation apply; see [consumer and platform rules](consumer-and-platform-rules.md)).
- **Daily routine:** orders in, orders shipped, messages answered, stock check on bestsellers.
- **Backup plan:** what happens if you're ill for three days in December.

## 5. Post-peak plan

- Returns window: expect a wave after gift holidays; set aside time.
- Leftover seasonal stock: bundle, discount, or store for next year (with a cost check).
- Reset processing times and banners.
- Thank-you or review request messages within platform rules.

## 6. Review (within a month of the peak)

```
Peak: ___
Revenue vs plan: ___
Sold out (and when): ___
Overstocked: ___
Shipping problems: ___
Lessons for next year: ___
Next year's key dates (draft): ___
```

## Worked example

A maker sells hand-poured candles. Last year's December peak was about four times a normal month. Capacity is 60 candles a week. To build stock for the peak, production must run through September and October. The plan: start the batch in early September, cut two slow scents, set custom orders to close in mid-November, order boxes in October. The decision is made in August, not December.

## Common mistakes

- Planning from the holiday date instead of the shipping cutoff.
- Forgetting packaging lead times.
- Running ads before stock arrives.
- No time budgeted for returns in January.
