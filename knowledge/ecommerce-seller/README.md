# Ecommerce Seller knowledge base

These docs back the listing, review, inventory, ads and season skills with templates, formulas and rule checklists. They're marketplace-agnostic.

## Which doc to use

- **[Listing template](listing-template.md)**: writing or refreshing a product listing. Title formula, photo shot list, description structure and a refresh log.
- **[Reorder point math](reorder-point-math.md)**: setting reorder points, safety stock and order quantities, with a worked example and seasonal adjustment.
- **[Season backwards plan](season-backwards-plan.md)**: planning a peak from the shipping cutoff backwards, maker capacity checks and the peak ops pack.
- **[Consumer and platform rules checklist](consumer-and-platform-rules.md)**: shipping promises, reviews, returns and sales tax basics (US, EU and UK, country-specific), and when to get professional advice.

## Ground rules

- Marketplace policies change often. Check the platform's current seller rules before acting on anything here; penalties can include losing the account.
- Tax and legal questions for a specific business go to an accountant or lawyer. These docs give general background only.
- Work from the seller's exported numbers; never touch their accounts.
