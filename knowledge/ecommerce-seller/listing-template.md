# Listing template

A listing has three jobs: be found (title and keywords), be clicked (main photo), and be bought without a message (description and photos answer the questions).

## Keyword research

- Type the product into the marketplace search and note the autocomplete suggestions.
- Look at the titles of the top-selling similar listings.
- Use the marketplace's own category and attribute names.
- Use words buyers use, not trade jargon ("baby blanket", not "receiving swaddle textile").

List them by intent: the phrase most likely to lead to a purchase goes first.

## Title formula

```
[Main search phrase] — [key attribute] [key attribute] — [size/variant] — [use or recipient]
e.g. Linen Napkins Set of 4 — Stonewashed, Machine Washable — 45 cm — Housewarming Gift
```

- Front-load the main phrase.
- Readable by a human. Keyword stuffing tends to look spammy, and platforms increasingly discourage it.
- Follow the platform's title length and character rules.

## Photo shot list

| Shot | Purpose |
|---|---|
| Main image on plain background | Readable as a thumbnail; meets the platform's main-image rules |
| Scale reference (in hand, next to a common object, or with dimensions overlay) | Prevents "smaller than expected" returns |
| In use / in context | Helps buyers imagine owning it |
| Detail / texture close-up | Shows quality |
| Variant grid (colours, sizes) | Reduces option confusion |
| Packaging or what's in the box | Sets expectations, especially for gifts |
| Back, underside, labels | Answers material and care questions |

Test the main image at thumbnail size on a phone. If you can't tell what it is, reshoot.

## Description structure

```
Hook (two lines): what it is and why it's good, in plain words.

Specifics:
| Size | ___ |
| Materials | ___ |
| Care | ___ |
| What's included | ___ |
| Made in / made by | ___ |

In use: one short paragraph — who it's for, how it's used.

Questions buyers ask:
- Q: ___  A: ___
- Q: ___  A: ___

Shipping and returns: processing time, shipping options, return policy summary.
```

Build the questions list from real buyer messages and return reasons. Update it whenever the same question arrives twice.

## Variants

- Check for the size or colour buyers keep asking for.
- Name options the way the platform and buyers do ("Small (20 cm)", not "S1").
- Each variant has its own photo where possible.

## Claims

Only claim what you can back up. Words like "organic", "hypoallergenic", "waterproof", "eco-friendly" or "handmade" may carry legal or platform meanings and need evidence. Product categories such as toys, cosmetics, food, electrical goods and children's items often have safety and labelling rules; check them for each market you sell to.

## Refresh log

Treat each change as an experiment.

```
SKU | Date | Change (one thing) | Before: views / conversion (period) | After: views / conversion (same length period) | Verdict
```

- Change one element at a time (title, main photo, price).
- Compare equal periods and watch for seasonal effects.
- Refresh quarterly, and whenever sales dip without an obvious cause.

## Common mistakes

- A beautiful main photo that's unreadable at thumbnail size.
- Dimensions buried in paragraph four.
- Copying a competitor's description word for word.
- Changing title, photo and price on the same day, then not knowing what worked.
