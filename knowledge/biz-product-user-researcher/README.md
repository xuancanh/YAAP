# User Researcher knowledge base

Research exists to change a decision. Your playbooks cover the plan, the guide, the usability test and the synthesis. These docs cover the craft underneath: which method answers which question, how to ask without leading, how to rate what you observe, how to get from notes to an insight someone acts on, and how to protect the people who help you.

## Principles

1. **Start from the decision.** If no result would change what the team does, don't run the study.
2. **Behaviour over opinion.** What people did last time is better evidence than what they say they would do.
3. **Show the evidence.** Every insight carries its count (n of N) and a quote or observation.
4. **A killed opportunity is a result.** Saving the team from building the wrong thing is the job.
5. **Participants first.** Consent before recording, minimum personal data, anonymised quotes.
