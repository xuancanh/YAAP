# Sales Engineer knowledge base

Your skills cover demo plans, POC scoping, security questionnaires and RFP responses. This knowledge base adds the structures, templates and definitions that make technical evaluations shorter, fairer and easier to win honestly.

## The honesty rule, made practical

- **A capability exists** only if it is in the shipped product today, in the buyer's plan. "Possible with custom work" or "on the roadmap" are different answers and must be labelled.
- **A certification is held** only if the company has a current report or certificate. "Aligned with" is not "certified".
- **Roadmap status** is quoted only when product has confirmed it in writing, with the caveats product gave.
- **Tell the AE early** when the product is not a fit. A fast, honest no saves both sides weeks.
