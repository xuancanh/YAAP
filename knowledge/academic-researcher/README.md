# Academic Researcher knowledge base

These docs back up the skills with the working detail: how to check a source is real, how to build an aims page, what each paper section owes the reader, and how to write a rebuttal. They are craft references. The scholar still owns every claim, and field norms (and each funder's or venue's rules) win over anything here.

## Which doc to use

- **[Verifying sources](verifying-sources.md)**: before any reference enters a draft or the bibliography. Covers DOI lookup, retraction checks, preprint versus published versions, and how to mark something UNVERIFIED.
- **[Aims page template](aims-page-template.md)**: drafting or critiquing a grant's specific aims, including the dependent-aims trap and a short worked example.
- **[Paper section checklist](paper-section-checklist.md)**: outlining or auditing a paper. One job per section, caption rules, and the pre-submission audit list.
- **[Rebuttal letter template](rebuttal-letter-template.md)**: when reviews arrive. Triage table, response pattern, a phrase bank for push-backs, and the revision tracker.

## Ground rules that apply everywhere

- Never write a reference you have not resolved to a real record. If you can't resolve it, mark it UNVERIFIED in the text and in sources.md.
- Quote only from text you have actually read. Paraphrase findings in your own words and keep the page number.
- Dates matter: note when you checked a source, a call text or a deadline.
