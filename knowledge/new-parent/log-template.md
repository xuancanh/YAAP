# Log template

At 3am the log has to take seconds. The parent should be able to type "f L 15" and be done. The value comes later: a clean record the midwife, health visitor or paediatrician can read.

## Quick-entry shorthand

Agree the shorthand once and save it in the profile.

| Type | Shorthand | Logged as |
|---|---|---|
| Breastfeed | `f L 15` / `f R 10` | time, side, minutes |
| Bottle | `b 90` | time, amount as the parent states it, unit they use |
| Sleep start / end | `s` / `w` | time; duration computed |
| Wet nappy | `n w` | time |
| Dirty nappy | `n d` (optional note: colour as the parent describes it) | time |
| Medicine (as prescribed) | `m <name>` | time and name only, exactly as the parent says |
| Note | `note …` | free text |

Time defaults to now. "5 min ago" or "at 2:10" adjusts it. Never ask follow-up questions at night; accept the entry and move on.

## Log format

```
## 2026-11-04
02:10 f L 15
02:30 n w
02:35 s
04:50 w
05:00 b 90 ml
05:20 n d  note: parent says "more watery"
```

## Daily summary (once a day, morning)

```
Yesterday: 8 feeds, 6 wet nappies, 3 dirty, sleep total 14h 10m, longest stretch 3h 20m
```

## Showing patterns without interpreting them

The log surfaces facts. Clinicians interpret them.

| Do | Don't |
|---|---|
| "Longest sleep this week: 4h 10m, Tuesday night." | "She's sleeping well." |
| "Fewer wet nappies today (3) than this week's daily range (5–7)." | "She might be dehydrated." / "That's fine." |
| "Feeds have been closer together since Sunday." | "It's a growth spurt." |
| "Would you like this summary for your health visitor?" | "You should feed more." |

If a pattern touches anything on the urgent list (fewer wet nappies, refusing feeds, fever, breathing changes), skip the summary and route to [When to get help now](when-to-get-help.md).

## Preparing for an appointment

Before a check-up, offer a one-page export:

- Last 7 days: feeds per day, wet and dirty nappies per day, sleep totals
- Notes the parent flagged
- The parent's questions, written in their words
- Weight readings the clinician recorded, as recorded (copy from the red book or chart; don't calculate percentiles)

After the visit, record what the clinician said, quoting them.

## Common mistakes

- Asking for detail at night.
- Adding judgment to the summary ("great day!") when the parent may be struggling.
- Comparing the baby with charts or other babies.
- Letting the log become a source of anxiety. If the parent says it's stressing them, offer to reduce what's logged to what their clinician asked for.
