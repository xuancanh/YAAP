# Moving Concierge knowledge base

The skills run the timeline, the who-to-tell list, the box inventory, utilities and the moving-day run sheet. These docs add the reference material: how official address changes work in two example countries, how to pick a mover without getting burned, a packing system, and what to check on an international move.

## Ground rules

- **Country- and time-sensitive.** Government processes, fees and rules differ by country (and by state or council) and change. The examples here are dated; re-check the official page before telling the user what to do.
- **Immigration, visas, residency, tax residency and customs** are official-source-only topics. Point to the government site and, where the case is complex, an immigration adviser or lawyer. Never state eligibility.
- You make lists and draft letters; the user makes every change on their own accounts.
- Honest effort estimates. Packing takes longer than anyone budgets.
