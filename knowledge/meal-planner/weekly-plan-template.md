# Weekly plan template

A good weekly plan fits the week's real shape. The trick is planning the week first and the food second.

## Planning order

1. **Map the week.** For each night: who's home, when, how much time and energy. Mark nights as *busy* (≤20 minutes), *normal* (30–45 minutes) and *free* (cook for fun or batch).
2. **Use what's ageing.** Check the pantry file: anything that must go this week anchors a meal early in the week.
3. **Pick anchors.** One batch-cook or big cook on a free night, feeding at least one later meal.
4. **Fill busy nights** with fast meals, leftovers or a freezer portion.
5. **Share ingredients.** Choose recipes that use the same perishable items, so half a bunch of coriander doesn't rot.
6. **Leave one flex night.** Leftovers, eggs on toast, or a takeaway. Plans with no slack fall over by Thursday.
7. **Check every meal** against allergies and restrictions, then derive the grocery list.

## Template

```
## Week of <date>
Household this week: <who, any guests, any away>
Use up: <items from pantry file>

| Day | Night type | Meal | Time | Uses up / makes | Notes |
|-----|------------|------|------|-----------------|-------|
| Mon | busy   |      | 20m  |                 |       |
| Tue | normal |      | 40m  |                 |       |
| Wed | busy   |      | 15m  | leftovers Sun   |       |
| Thu | normal |      |      |                 |       |
| Fri | flex   |      |      |                 |       |
| Sat | free   |      |      |                 |       |
| Sun | free   | batch| 90m  | makes Mon + freezer |   |

Prep ahead: <what to do Sunday, what to defrost when>
Lunches: <if planned>
Allergy check done: yes / no
```

## Rules of thumb

- **Perishables early, pantry late.** Fish and salad leaves on Monday or Tuesday; tins, frozen and dried foods later in the week.
- **Leftover windows.** Leftovers planned for a later night must fit the food safety window (see [Food safety basics](food-safety-basics.md)). Past that, freeze on the day you cook.
- **Defrost reminders.** If Thursday uses a freezer portion, the reminder goes on Wednesday night.
- **One new recipe a week, at most,** and not on a busy night.
- **Repeat winners.** A rotating set of reliable meals is easier than novelty every week.

## Worked example

Family of four, two working parents, swimming lessons Tuesday, one child dislikes mushrooms, no allergies.

| Day | Type | Meal | Notes |
|---|---|---|---|
| Sun | free | Roast chicken, potatoes, carrots | Keep extra chicken |
| Mon | busy | Chicken wraps with leftover chicken | 15 min |
| Tue | busy | Pasta with tomato sauce from freezer | Defrost Mon night |
| Wed | normal | Salmon, rice, green beans | Fish early in week |
| Thu | normal | Chicken-stock vegetable soup, bread | Stock made from Sunday's carcass on Monday, frozen, defrosted Wed night |
| Fri | flex | Pizza night | |
| Sat | free | Chilli (double batch) | Freeze half |

Shared ingredients: chicken across three meals; onions, carrots and tomatoes across four.

## Common mistakes

- Planning seven ambitious dinners for a week with three late nights.
- No flex night.
- Leftovers planned beyond the safe window.
- Building the list from recipes without checking the pantry first.
