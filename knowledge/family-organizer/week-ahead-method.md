# Sunday week-ahead method

Fifteen minutes on Sunday saves a week of "who's picking up?" The output is one page: the week's grid, the clashes, and the prep.

## Inputs to gather

- Each person's fixed commitments: work hours, school, clubs, lessons, appointments.
- New items from the week: school notices, invitations, medical appointments, deliveries.
- Who has the car(s), and any travel.
- Meals planned (or not) and the shopping list.

## The grid

```
Week of <date>
|        | Mon | Tue | Wed | Thu | Fri | Sat | Sun |
| Adult A|     |     |     |     |     |     |     |
| Adult B|     |     |     |     |     |     |     |
| Child 1|     |     |     |     |     |     |     |
| Child 2|     |     |     |     |     |     |     |
| Driving|     |     |     |     |     |     |     |
| Dinner |     |     |     |     |     |     |     |
```

The "Driving" row is the one that catches most problems. For every activity outside home, write who drops off and who collects.

## Clash detection checklist

- [ ] Two people need to be in two places at once (same adult, or the only car).
- [ ] A pickup falls inside someone's work hours or commute.
- [ ] An activity ends after a younger child's bedtime routine starts.
- [ ] A day with no dinner plan and late activities (plan something quick or batch-cooked).
- [ ] A deadline (form, payment, costume, project) without a prep slot.
- [ ] A birthday party without a present bought.

For each clash, list two or three fixes: swap with the other adult, lift-share with another family, move the activity, or skip it. The adults choose.

## Prep list

Turn the week into tasks with a day and an owner:

- "Wed: PE kit washed (A)"
- "Thu: £5 for the school trip in envelope (B)"
- "Fri: present for Sam's party, wrapped (A)"

## Sharing the week

Post the grid and prep list in the shared folder or family chat. Keep it short enough to read on a phone. Highlight changes from last week.

## Worked example

Tuesday: Child 1 football 17:00–18:00 across town; Child 2 piano 17:30 nearby. Adult A works until 17:30; Adult B has the car. Clash: B can't do both runs. Options: (1) lift-share football with a teammate's family, B covers piano; (2) A leaves early on Tuesdays; (3) move piano to Wednesday. The family picks option 1 and the assistant drafts a message to the other parent offering a return favour on Thursdays.

## Keeping it light

- The routine should take minutes. If it's a chore, cut steps.
- Review only the coming week in detail; glance at the next week for big items.
- Celebrate the smooth weeks too: note what made them work.

## Common mistakes

- Planning activities but not the transport.
- Holding the plan in one adult's head.
- Over-scheduling: if every evening is full, flag it gently.
- Forgetting term dates, inset or teacher-training days and public holidays.
