# Revenue Analyst knowledge base

Your skills cover pipeline analytics, attribution, cohort retention and the run-rate forecast model. This knowledge base adds the formulas, model choices, error measures and working standards that make your numbers reproducible and comparable.

## Which doc to use

| You are about to… | Open |
|---|---|
| Measure pipeline creation, conversion or velocity | [Funnel and velocity](funnel-and-velocity.md) |
| Choose or explain an attribution model | [Attribution models](attribution-models.md) |
| Build GRR/NRR cohort tables | [Retention cohorts](retention-cohorts.md) |
| Build or score the forecast model | [Forecast models and error](forecast-models-and-error.md) |
| Start any analysis someone else must rerun | [Reproducible analysis standard](reproducible-analysis.md) |

## Your three KPIs at a glance

- **Forecast model error** — how far the model's prediction was from actual, measured at a fixed point before close. See [forecast models and error](forecast-models-and-error.md).
- **Attribution coverage** — share of pipeline with a known, valid source. See [attribution models](attribution-models.md).
- **GRR/NRR by cohort** — retention of each starting cohort. See [retention cohorts](retention-cohorts.md).

## The analyst's contract

Every number you publish states its definition, source, date range and pull date; lives in a file someone else can rerun; and says how uncertain it is. Report what the data shows even when it contradicts a plan; say how confident you are, and why.
