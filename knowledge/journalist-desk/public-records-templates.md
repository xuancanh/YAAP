# Public records templates

Records laws differ by country, state and city, and each has its own clock, fees and exemptions. Check the specific law every time. Two common reference points:

- **US federal FOIA:** agencies must determine a request within 20 working days of receipt (excluding weekends and federal holidays), extendable by up to 10 working days in "unusual circumstances" with written notice. Appeals of a denial can be filed within a period the agency sets, which must be at least 90 days. Fees for news media requesters are limited to duplication when the request isn't for commercial use. (5 U.S.C. § 552)
- **UK FOI Act:** the ICO explains that public authorities must respond within 20 working days; an extension for public-interest considerations is possible, but the ICO says the total shouldn't exceed 40 working days.

US state laws vary widely; the Reporters Committee's Open Government Guide summarises each state.

## Request template

```
To: [FOI/records officer, agency]           Date: [date]
Re: Request under [law name and section]

I request copies of the following records:
1. [Record described precisely: type, author/recipient, subject, date range]
   e.g. "All emails between [office] and [company] containing the term
   '[project name]', from 1 January 2025 to 30 June 2025."
2. [...]

Format: electronic, in native format where possible (e.g. spreadsheets as .xlsx/.csv, not PDF printouts), with metadata.

Fees: I am a representative of the news media [outlet], and this request is not for commercial use. [If the law allows: I request a fee waiver because disclosure is in the public interest: brief reason.] Please contact me before incurring fees above [amount].

If any part is withheld, please release all reasonably segregable portions and cite the specific exemption for each redaction.

I'm happy to discuss narrowing the request if that helps. Contact: [email, phone].

[Name]
```

Tips: use the agency's own names for records (form numbers, database names, report titles) from prior releases or published retention schedules. Ask for a date range you can justify; overly broad requests invite delay.

## Follow-up when the clock lapses

```
Re: [law] request [reference no.], submitted [date]

The statutory deadline for a response was [date]. I haven't received a determination. Please tell me the status and when I can expect the records. [Optional: I'm open to a rolling release of records as they're processed.]
```

## Appeal skeleton

```
Re: Appeal of decision on request [ref], dated [date]

I appeal the [denial / partial denial / fee decision / adequacy of search].

1. Exemption [X] was applied to [records]. [Why it doesn't fit, or why the public interest favours release, citing the exemption's own wording.]
2. The search appears inadequate because [specific records known to exist were not produced].
3. [Fee or format issue.]

I ask that you [release the records / conduct a new search / reconsider the fee].
```

Check the appeal deadline in the decision letter and diary it immediately. If an appeal fails or the agency stays silent, a media law clinic or the outlet's lawyer can advise on next steps (in the US, litigation; in the UK, a complaint to the ICO).

## Tracker

```
| Ref | Agency | Law | Sent | Due | Status | Last contact | Next action |
```

Statuses: drafted → sent → acknowledged → clarification → fee notice → partial release → complete / denied → appeal → closed.

## Common mistakes

- Sending to the wrong office.
- Vague requests ("all records about the stadium").
- Not counting the clock, so lapses go unchased.
- Not logging what's missing from a release compared with the request.
