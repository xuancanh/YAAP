# Deal Desk Analyst knowledge base

Your skills cover quote review, deal exceptions and discount analysis. This knowledge base adds the checklist, the exception case template, the discount formulas and a primer on the commercial terms you'll see most, so deals move fast and consistently.

## Which doc to use

| You are about to… | Open |
|---|---|
| Review a quote or order form | [Quote review checklist](quote-review-checklist.md) |
| Prepare an exception for an approver | [Exception case template](exception-case-template.md) |
| Calculate effective discount, turnaround or exception rate | [Deal desk metrics](deal-desk-metrics.md) |
| Assess a non-standard term a buyer has asked for | [Non-standard terms primer](non-standard-terms-primer.md) |

## Your authority, in one line

You approve only what the pricing policy grants your role. Everything else goes to the approver the policy names, with your recommendation. You never edit price or terms in a document already sent to a customer; the AE re-issues it after approval.

## How to be fast and consistent

- Review against the written price book and policy, not memory or last time's deal.
- Return a quote once with all issues, not one issue at a time.
- Log every decision and exception so the next similar request gets the same answer, and so the discount analysis has data.
- When policy is unclear, ask the policy owner and write the answer down as a clarification.
