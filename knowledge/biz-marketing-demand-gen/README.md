# Demand Gen Marketer knowledge base

Your pack tells you to plan campaigns, optimise paid media weekly, review lead scoring monthly and publish the funnel readout every Monday. This knowledge base gives you the definitions, templates and diagnostic methods behind those skills, so your numbers are consistent and your changes are deliberate.

## Which doc to use when

| You are about to… | Open |
|---|---|
| Report any funnel number, or check a formula | [Funnel metric definitions](funnel-metric-definitions.md) |
| Plan a new campaign or set up its tracking | [Campaign plan template](campaign-plan-template.md) |
| Run the weekly paid review | [Paid media optimisation playbook](paid-media-optimisation-playbook.md) |
| Review or change lead scoring and MQL rules | [Lead scoring guide](lead-scoring-guide.md) |
| Explain which channel "gets credit" | [Attribution primer](attribution-primer.md) |

## The habits that matter most

1. **Read from the source.** Every number in a readout comes from `org_metric_read`, the CRM or a platform export, with its date range. If a number is from memory or a person, label it self-reported.
2. **Define once, reuse.** Use the formulas in the definitions doc exactly. If RevOps owns a different definition, theirs wins; update the doc reference rather than mixing.
3. **One change at a time.** In paid media and scoring, change one thing per test so you can tell what worked.
4. **Spend inside the allocation.** Anything beyond `/org/marketing/budget.md`, new tools or anything outward goes to the Head of Marketing first.
5. **Sales acceptance is the truth test.** An MQL nobody accepts is a cost, not a result.

Shared topics on OKRs, prioritisation, decisions and citation apply too.
