# Calendar triage rules

The calendar should show the user's priorities. Triage each request against them instead of filling gaps first-come, first-served.

## Start from the priorities

Keep a short list, agreed with the user and reviewed monthly: the two or three outcomes that matter this quarter, the people whose time always comes first, and the protected blocks (focus, family, exercise). Every triage decision refers back to it.

## Decision guide for a new request

1. **Does it serve a current priority or a key relationship?** If no, suggest declining or delegating.
2. **Does the user need to be there, or would an update do?** If an update would do, suggest asking for notes instead.
3. **Is the length right?** Many meetings fit in less time than booked. Propose a shorter slot.
4. **Is the timing right?** Put deep work in the user's best hours (ask them which) and meetings around it.
5. **Is there prep?** If the meeting needs prep, book the prep time too.

## Clash resolution order

When two things collide, a sensible default order (confirm with the user):

1. Hard external commitments (customers, board, legal deadlines, travel).
2. The user's stated top priorities.
3. Their manager or key stakeholders.
4. Recurring internal meetings (easiest to skip once).
5. Optional or informational meetings.

If two items sit at the same level, ask the user one question: "Board prep or the customer call at 15:00? I can move whichever you drop to Thursday."

## Protecting focus time

- Block focus time as real events, with a name ("Deck writing") rather than "Busy".
- Treat it as moveable only by the user.
- Leave buffers between back-to-back meetings where you can, and travel time before off-site ones.
- Watch for days with no gap for lunch, and flag them.

## Decline wording

Short and warm, with an alternative where there is one:

- "Thanks for the invite. Ana can't make this one; could you share notes afterwards?"
- "Ana's booked then. Could 20 minutes on Thursday at 11 work instead?"
- "Ana is focusing on the launch this month, so she's handing this to Ben, who leads it day to day."

## Weekly calendar review

Every Friday, look at the next two weeks:

- Is there focus time on most days?
- Is each priority getting time?
- Are there meetings without an agenda or a clear owner?
- Any travel days that are over-booked?
- Which recurring meetings could be shortened or ended?

## Common mistakes

- Accepting by default because a slot is free.
- Protecting focus time by name only, then giving it away to the first request.
- Moving the same meeting repeatedly, which damages the relationship more than a clean decline.
- Forgetting time zones on remote meetings: always state both times when they differ.
