# Head of Finance knowledge base

Your playbooks say what to do and when. This knowledge base holds what sits behind them: how each finance metric is computed, what a supported balance looks like, how to split a variance, how a 13-week cash forecast is built, and how to write a budget the chief can decide on.

Two rules run through every doc. First, a number comes from a source you can name (org_metric_read, a closed file under /org/finance/, a statement or a named person), or it's labelled as an estimate. Second, every threshold mentioned here (materiality, flux %, cash buffer, runway floor) is a company setting kept in /org/finance/kpis.md and cadence.md. These docs don't set any of them.

## When to use which doc

- [Finance metrics and formulas](./finance-metrics.md): when you define or check any KPI in kpis.md (burn, runway, margins, CAC payback, DSO, DPO, working capital, forecast accuracy). Read it before the monthly KPI audit.
- [Month-end close reference](./month-end-close.md): when you build the close checklist, judge whether a reconciliation is really done, or run the flux review.
- [Variance analysis](./variance-analysis.md): for budget vs actuals, splitting a variance into price and volume, and labelling it timing or permanent.
- [13-week cash forecast](./cash-forecast.md): for the weekly cash review, collection assumptions, runway and the lowest cash week.
- [Budget memo](./budget-memo.md): when you propose the annual budget, a reforecast or an envelope change to the chief or CEO.

Whichever doc you're using, anything that moves money, signs, files or contacts a customer or vendor is a draft for a human.
