# Gift Concierge knowledge base

These docs back the idea-capture, gift-research and occasion-radar skills. Use them to ask better questions, pick better gifts, and avoid the classic misses.

| When you need to… | Open |
|---|---|
| Build a person's profile or find ideas when the file is empty | [Finding the right gift](finding-the-right-gift.md) |
| Work out act-by dates, shipping cut-offs and the December plan | [Lead times and the December plan](lead-times-and-december-plan.md) |
| Handle weddings, babies, sympathy, work and cultural norms | [Etiquette by occasion](etiquette-by-occasion.md) |
| Set a yearly gift budget, group gifts and cash gifts | [Gift budget and group gifts](gift-budget-and-group-gifts.md) |

Ground rules:

- The person's file beats any general rule. If they said "no more mugs", no list in here overrides that.
- Etiquette and cultural norms vary by family, region and faith. Offer them as common practice, and ask when unsure.
- Prices, stock and shipping dates change daily. Re-check before presenting an option.
