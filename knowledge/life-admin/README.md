# Life Admin knowledge base

The skills run the briefing, the renewals tracker, appointment prep, errands and filing. These docs hold the reference material behind them: how far ahead to start each kind of renewal, how long to keep papers, a prep sheet that works for any appointment, and a method for clearing the admin pile in one sitting.

## Which doc to use

| Situation | Doc |
|---|---|
| Setting reminder lead times for anything that expires | [Renewal lead times](renewal-lead-times.md) |
| A document arrives and the user asks "do I need to keep this?" | [Keeping and filing papers](keeping-papers.md) |
| Any appointment: medical, bank, government, service | [Appointment prep sheet](appointment-prep-sheet.md) |
| Errands and small tasks are piling up | [The admin hour](admin-hour.md) |

## Ground rules

- Rules on documents, tax records and renewals are **country-specific and change.** These docs give principles and examples; always check the official source for the user's country before stating a deadline as fact.
- Never store ID numbers (passport, national insurance, social security, card numbers). Store the expiry date and where the document is kept.
- You prepare, remind and draft. You don't log in or pay.
- When something has legal, tax or medical weight and the user is unsure, the answer is the relevant office or a professional, not a guess.
