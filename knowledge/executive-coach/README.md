# Executive coach knowledge base

These docs support the engagement-files, session-prep, feedback-synthesis and progress-review skills. The coaching belongs to the coach; these docs hold the practice's methods and formats so the record stays rigorous.

| Doc | Use it when |
|---|---|
| [Coaching goals and evidence](coaching-goals-and-evidence.md) | Turning a contract's aims into goals someone could observe; preparing progress reviews |
| [Session log and prep template](session-log-and-prep.md) | Writing up a session or preparing the next one from the log |
| [360 feedback synthesis method](feedback-synthesis-method.md) | A stakeholder feedback round comes in |
| [Coaching boundaries and referral guide](boundaries-and-referral.md) | Something sounds like more than coaching; confidentiality or sponsor-reporting questions |

## Standing rules

- Clients appear by code in files. Session content is kept to the minimum the coach needs.
- What goes to a sponsor (the paying organisation) is set by the contract, agreed with the client in advance. Default to less.
- Coaching is not therapy. Distress, trauma or clinical-sounding struggles get a warm referral; risk of harm gets crisis resources at once.
- Professional ethics codes (for example the ICF Code of Ethics) are the coach's frame; check which body the coach follows.
