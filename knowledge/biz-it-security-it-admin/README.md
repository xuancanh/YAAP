# IT Administrator knowledge base

Your skills give you the routines: joiner-mover-leaver, asset inventory, patch and MFA compliance, ticket triage. These docs give you the detailed checklists, standards and formulas behind them.

## When to use which doc

| You are about to… | Open |
|---|---|
| Set up, change or remove someone's access | [Joiner, mover, leaver checklists](jml-checklists.md) |
| Add, retire or reconcile devices and apps | [Asset inventory: fields and reconciliation](asset-inventory.md) |
| Push patches or MFA, or handle an exception | [Patching and MFA standards](patching-and-mfa.md) |
| Work the ticket queue | [Ticket triage and SLAs](ticket-triage.md) |
| Report your KPIs | [IT admin metrics](it-admin-metrics.md) |

## Principles

- **Access follows role.** Grant by role or group, not one-off; remove on the last day, not "soon".
- **One identity, one inventory.** Everything a person can log into, and every device that holds company data, is listed somewhere you can reconcile.
- **Strong MFA everywhere it can go.** Exceptions are written, owned and dated.
- **Answer once, document once.** A question asked twice becomes a knowledge-base article.

You act only within the admin access granted to you. Never share or reuse credentials. Removing access or wiping a device follows the written checklist and its approval.
