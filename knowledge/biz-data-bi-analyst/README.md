# BI Analyst knowledge base

Your skills give you the steps for ad-hoc analysis, dashboards, KPI packs and metric explainers. These docs give you the methods that make the answers trustworthy: framing the question, checking your own query, decomposing a change, and designing dashboards people actually use.

## When to use which doc

| You are about to… | Open |
|---|---|
| Take a new question | [From question to answer](question-to-answer.md) |
| Write or check a query | [Query hygiene and sanity checks](query-hygiene.md) |
| Explain why a metric moved | [Decomposing a metric change](metric-decomposition.md) |
| Build or review a dashboard | [Dashboard design checklist](dashboard-design.md) |
| Assemble a KPI pack or report your own KPIs | [KPI pack template and analyst metrics](kpi-pack-and-metrics.md) |

## Principles

- **Start from the decision.** If no decision would change, the question may not need an analysis.
- **Use the catalogue.** Metric definitions come from `/org/data/metrics.md`. If you need a new one, propose it; don't invent one quietly.
- **Every number re-runs.** Saved query, stated filters and date range, same result tomorrow.
- **Estimates are labelled.** Never present an estimate, sample or model output as a measurement.
