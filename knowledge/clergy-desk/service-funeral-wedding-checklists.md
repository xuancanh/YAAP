# Service, funeral and wedding checklists

The tradition decides the shape and content. These lists make sure every element has an owner, the right materials and a time.

## Weekly order of service

Capture the tradition's usual pattern once as a template, then copy it each week.

| Time | Element | Owner | Materials | Confirmed |
|---|---|---|---|---|
| 0:00 | Welcome | | | |
| | [tradition's element] | | text / music ref | |
| | Readings | reader names | text sent | |
| | Sermon / address | | | |
| | [tradition's elements] | | | |
| | Notices (max 3 spoken) | | rest to newsletter | |
| | Closing | | | |

Weekly checklist:

- [ ] Readings and music chosen per the tradition's calendar or the minister's plan.
- [ ] Each participant asked with what they need: text, timing, arrival time, where to stand.
- [ ] Midweek: chase anyone unconfirmed; substitutes lined up.
- [ ] Slides or printed order proofread (names, numbers, dates).
- [ ] Sound and tech notes: microphones, recordings, livestream if used.
- [ ] Notices triaged: the three that matter are spoken; everything else goes to print or newsletter.

After the service, one line: what ran long, what worked. Change the template when the same note shows up twice.

## Funeral checklist

Funerals have short timelines and no second chances. Check names and dates twice.

**First contact with the family (within a day or two):**

- [ ] Condolences; confirm who is the main family contact.
- [ ] Funeral director's name and contact; date, time and venue options.
- [ ] Burial, cremation or other, per family and tradition.
- [ ] Full name, preferred name, pronunciation, dates. Spell names back.

**Planning visit:**

- [ ] Family's wishes for readings, music, tributes, symbols, dress.
- [ ] Life story notes for the address (with care for difficult family dynamics). Ask what the family wants said and not said.
- [ ] Who speaks, for how long; request tributes in writing ahead.
- [ ] Printed order: proof sent to family; approval received.
- [ ] Venue logistics: arrival, seating for family, accessibility, livestream.

**Day before:** order printed; participants confirmed; timings agreed with the funeral director; address read aloud and timed.

**After:** note the date for anniversary contact and add bereavement follow-ups to the care list.

## Wedding checklist

Legal requirements for marriage differ by country and state (notice periods, licences, registrars, who can officiate, witnesses). Check the local rules early and confirm the minister's authorization to officiate.

**At booking:**

- [ ] Date, time, venue, rehearsal date.
- [ ] Legal paperwork requirements and deadlines for this jurisdiction.
- [ ] The tradition's preparation requirements, if any.
- [ ] Fees and what they cover (venue, music, verger, etc.).

**Planning meetings:**

- [ ] Order of service drafted from the tradition's rite; couple's choices for readings and music.
- [ ] Names and pronunciation confirmed.
- [ ] Photography and video rules for the venue.
- [ ] Participants: readers, musicians, witnesses.

**Final weeks:** proof of order of service; rehearsal plan; legal documents checked; who signs and where.

**On the day:** register or paperwork ready, pens, rings with the right person, timings with photographer.

## Common mistakes

- A misspelled name in a funeral order. Read it aloud with the family.
- Unlimited tributes. Agree lengths ahead and ask for them in writing.
- Discovering a legal notice period too late for a wedding.
