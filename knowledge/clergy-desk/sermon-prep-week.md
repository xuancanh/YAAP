# Sermon preparation week

Good sermons are usually written over several short sessions, not one long one. Ideas need time to settle, and a Saturday-night draft has no room for a second thought. Adapt the days to the minister's week; keep the order.

## The arc (for a weekend service)

| Day | Session (30-60 min) | Output |
|---|---|---|
| Mon/Tue | Read the text several times, aloud once. Map its structure. Own study and the tradition's commentaries. | Notes: what the text says, questions it raises |
| Wed | Ask what this text says to these people this week. | The one sentence (below) |
| Thu | Outline with time weights; pick illustrations. | Outline |
| Fri | Draft in the chosen format. | Manuscript, extended outline or notes |
| Sat | Read aloud, time it, cut. | Final, with timing |

If the week collapses (a funeral, a crisis), the minimum is: the sentence by midweek, an outline the day before.

## The one-sentence test

Before outlining, write the sermon's message as one sentence a listener could repeat on Tuesday. Then ask: "What should they do, feel or believe differently?"

If you can't write one sentence, or you've written three, you probably have three sermons. Pick this week's and file the others as seeds for future weeks.

## Outline shapes

Pick the shape that suits the text and the minister's style, recorded in the voice file.

- **Classic points:** introduction, two or three movements that each develop the one sentence, application, close.
- **Problem, grace, response:** name a real tension, bring the text's answer as the tradition understands it, then what to do with it.
- **Narrative:** tell the text's story, pause at its turning point, carry the listener into their own story.
- **Question-led:** start with a question people actually ask, let the text answer, end with the next question.

Time weights: assign minutes to each section against the usual preaching length. The introduction is often too long; aim to reach the text quickly.

## Illustration log

Keep one running file. Capture things when you notice them, not when you need them.

```
Title: ___                 Theme tags: ___
Source: [own experience / book p. / news, date]  Permission needed? ___
Story (2-4 lines): ___
Used: [date, service, text]
```

Check the "used" column before reusing a story. Personal stories involving others need their consent, and congregation stories should never be recognizable without permission.

## Read-aloud pass

Read the draft aloud at preaching pace and mark:

- Sentences that run out of breath: split them.
- Abstract nouns piled up: swap for a concrete image or example.
- Transitions the ear can't follow: add a signpost ("Here's the second thing").
- Anything over time: cut the weakest illustration first.

## Archive

File each sermon with date, text, the one sentence, series and themes. A year on, the archive shows which texts and themes have been covered and which haven't, which helps series planning.

## Common mistakes

- Starting to write before deciding the one sentence.
- Using every good commentary insight; the study is wider than the sermon.
- Application that's vague ("let's all try to be better"). Name a concrete situation.
- Leaving the conclusion to improvisation.
