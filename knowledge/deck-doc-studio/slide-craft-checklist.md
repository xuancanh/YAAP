# Slide craft checklist

Each slide makes one point, and the title says what it is. Everything else on the slide supports that title.

## Titles

- Write titles as full sentences that state the takeaway: "Churn concentrates in month two", not "Churn analysis".
- Keep them to one or two lines.
- Read only the titles, in order: they should tell the whole story.

## Body

- One point per slide. If you need "and" in the title, it's probably two slides.
- Evidence supports the title. Remove anything that doesn't.
- Text: a few short lines at most if you're presenting live. If the deck will be read without a presenter, more text is fine, but structure it with clear headings.
- Large enough to read from the back of the room. If you have to shrink text to fit, cut content instead.

## Charts

- Pick the chart for the comparison:
  - Change over time → line.
  - Comparing categories → bar (horizontal if labels are long).
  - Parts of a whole with few parts → stacked bar, or a pie only with a few slices.
  - Relationship between two measures → scatter.
- Highlight the one series or bar that makes the point; mute the rest.
- Label directly on the chart where possible instead of a separate legend.
- State the takeaway in the title, not "Revenue by region".
- Axes labeled with units; start bar charts at zero.
- Cite the data source and date in small text.

## Tables

- Only the rows and columns needed for the point.
- Highlight the key cell or row.
- Align numbers right, with consistent decimals.

## Visual consistency

- One font family, a small set of sizes.
- A limited palette from the house style, with one accent colour for emphasis.
- Consistent placement: titles in the same spot, same margins.
- Images that illustrate the point, not decoration.

## Accessibility

- Sufficient contrast between text and background.
- Don't rely on colour alone to carry meaning; add labels or patterns.
- Add alt text to images and charts where the format supports it.
- Avoid flashing animations.

## The appendix

Move here: detailed methods, backup analyses, full data tables, answers to likely questions. Reference appendix slides by number from the main line ("see A3"). A strong appendix lets the main deck stay short.

## Review checklist

- [ ] Titles alone tell the story.
- [ ] Each slide has one point.
- [ ] Every chart's title is its takeaway; the key data is highlighted.
- [ ] No text smaller than the house minimum.
- [ ] Numbers match the source; totals add up.
- [ ] Sources and dates noted on data slides.
- [ ] The ask or decision is explicit, early enough, and repeated at the end.
- [ ] House style applied: fonts, colours, heading case, date format.
- [ ] The main line fits about two-thirds of the slot.
- [ ] Spell-check and a read-through for names and numbers.

## Common mistakes

- Topic titles.
- Full paragraphs pasted from a document.
- Charts with every series in a different bright colour.
- Ten bullets on one slide, read aloud.
- Last-minute number changes that miss the summary slide.
