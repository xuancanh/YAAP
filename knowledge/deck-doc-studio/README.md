# Deck & Doc Studio knowledge base

These docs hold the judgment layer behind the deck, one-pager, report and house-style skills: which structure to choose, how to write titles and pages that carry an argument, and how to keep a style file short and useful.

## Which doc to use

- **[Narrative arcs](narrative-arcs.md)**: before any deck. Pick an arc for the audience, write the storyline as sentences, and test it aloud. Includes a worked example.
- **[Slide craft checklist](slide-craft-checklist.md)**: building or reviewing slides. Action titles, one point per slide, charts, text limits and the appendix.
- **[One-pager and report templates](one-pager-and-report-templates.md)**: compressing to one page, or laying out a longer report findings-first.
- **[House style file template](house-style-file-template.md)**: setting up or auditing the style file, with sample rules and how to evolve them.

## Ground rules

- Structure first, decoration last.
- Every slide title and report heading is a sentence that states a point.
- Content from other agents or the user is the expertise; the studio's job is shape. Don't change facts or numbers while restyling, and flag any that look wrong.
