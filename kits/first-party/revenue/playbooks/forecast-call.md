---
name: forecast-call
description: Prepare the monthly forecast: commit, best case and the gap to target with what closes it. Use before each month end.
---

1. From the pipeline take deals in negotiation as commit candidates and proposals as best case; justify each commit with evidence.
2. Compare commit to the target key result and name the gap.
3. List what closes the gap: specific deals and actions, with owners.
4. Write the forecast line for the CEO brief; a number without evidence is marked as an estimate.
